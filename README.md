# 組織内リーダーシップ評価のためのソーシャルネットワーク分析プロトコル設計書 

## 本書の概要
本書は、組織内のリーダーシップ構造とインクルージョン状況を評価するための、ソーシャルネットワーク分析（ONA）に基づく調査・分析プロトコルの設計書です。
特定の企業課題（女性社員の構造的ポジション評価）に対し、適切な問いの設定からデータ収集手法、分析指標、スコアリングモデル、報告書構成、顧客への成果物の届け方までを一貫して設計したものです。

## 背景
従来のリーダーシップ評価が個人属性や役職に依存しがちである一方で、本プロトコルは「組織内の関係性データ」に着目し、構造的位置づけ（中心性、情報アクセス、影響力、スポンサーシップ）を測定する手法を定義しています。本プロトコルは、組織内のリーダーシップ評価における構造的バイアスを客観的に可視化し、役職や属性に依存しない評価手法を求めるクライアントの依頼を受けて設計されました。

## 構成
- Phase 0：オンボーディング（顧客との要件定義、データアクセス設計、同意取得フロー）
- Phase 1：データ収集（2種類のアンケート設計、層化サンプリング設計、メタデータ処理方針）
- Phase 2：分析（ネットワークグラフ構築、E-I Index、中心性分析、認知調査との三角測量）
- Phase 3：スコアリング（企業規模別の重み付けモデル、インタープリテーション基準）
- Phase 4：デリバリー（報告書構成、顧客へのプレゼンテーション設計、推奨施策の具体例）

## 本書が示す能力
- ビジネス課題を計算可能な分析設計に変換する能力
- 多様なデータソース（アンケート、メタデータ、組織データ）の統合設計
- 技術的妥当性と倫理的配慮（再識別リスク、匿名化、同意管理）の両立
- 顧客が実行可能な形への落とし込み（具体的な推奨施策、納品物構成、会議設計）

## スコープについて
本書は、調査設計・手法論定義フェーズの成果物です。
実装ロードマップ、工数見積もり、運用フローまでを含む、実行可能な設計書として完成しています。
